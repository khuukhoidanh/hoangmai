# Project Rules

## Development

- Follow the existing project structure.
- Write clean and maintainable code.
- Preserve existing functionality.

## Verification

- Check modified files for errors.
- Run available lint, build and tests.
- Fix errors and rerun relevant checks.
- Inspect git diff before finishing.
- Never claim a test passed without running it.
- Check the website / files before report

## Reporting

- Summarize changes.
- List modified files.
- Report actual test results.
- Mention unresolved issues.
